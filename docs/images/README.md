# Documentation images

Use accepted screenshots from the final 0.7.0 build. Do not use screenshots that show private file paths, copyrighted score pages, private recordings, tracebacks, or unfinished dialogs.

Use descriptive lowercase names with hyphens:

- `application-main-window.png`
- `first-run-playback-setup.png`
- `instrument-library-manager.png`
- `track-mixer.png`
- `takes-panel.png`
- `alignment-dialog.png`
- `score-analysis.png`
- `reference-audio-analysis.png`
- `export-dialog.png`

Recommended capture rules:

- use the same Windows scaling for all screenshots
- crop unnecessary desktop background
- keep text readable at GitHub width
- use public-domain or synthetic test content
- hide usernames and absolute paths
- capture only accepted behavior

Screenshots are intentionally not fabricated in the initial source package. Add them after the target-machine smoke test.
