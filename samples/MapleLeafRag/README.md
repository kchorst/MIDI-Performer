# Maple Leaf Rag Sample

This exercise uses Scott Joplin's *Maple Leaf Rag* as a MIDI-only starting point. The work and Mutopia edition are identified by Mutopia as public domain.

Run from the repository root:

```powershell
.\.venv\Scripts\python.exe samples\MapleLeafRag\download_sample.py
```

The script downloads `maple-leaf-rag.mid`, verifies the Standard MIDI File header, calculates a SHA-256 checksum, and writes `maple-leaf-rag-SOURCE.txt` beside it.

- Source page: <https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=23>
- Direct MIDI source: <https://www.mutopiaproject.org/ftp/JoplinS/maple/maple.mid>
- Mutopia ID: `Mutopia-2011/11/13-23`
- Status stated by Mutopia: Public Domain, CC No Rights Reserved

Scott Joplin wrote, "It is never right to play Ragtime fast." The warning is used here as interpretive context and is not a claim that the downloaded MIDI contains that text.

Use the sample as a first exercise:

1. Listen to Original.
2. Reduce tempo until the syncopation and structure speak clearly.
3. Compare instrument libraries.
4. Review the piano rendering and level.
5. Create Light and Medium Takes.
6. Compare them with Original.
7. Keep the interpretation you prefer, not simply the one with the most change.

Historical reference for Joplin's tempo warning: <https://www.loc.gov/static/programs/national-recording-preservation-board/documents/RagtimeScottJoplin.pdf>
